# Ore Creepers Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **Ore Creepers Mod** by its original author.

- Original: https://www.9minecraft.net/?p=77096
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.25.0+

This port contains **no original assets**. Put your own copy of the original jar (`orecreepers1.7.10_v.1.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures/sounds from it at runtime.
